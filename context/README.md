# Contexto do projeto

Aqui ficam os documentos de referência que ajudam os agentes a entender o projeto: specs, decisões, exemplos e anotações. Escreva-os em markdown (`.md`).

Os prints de referência ficam só neste computador, em `context/prototype/`, que está no `.gitignore` e não vai para o repositório.

## O que há aqui

- `design.md`: regras de uso do sistema de design.
- `prototype/` (só local): prints de referência do tabuleiro.
