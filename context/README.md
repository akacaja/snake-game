# Contexto do projeto

Aqui ficam os documentos de referência que ajudam os agentes a entender o projeto: specs, decisões, exemplos e anotações. Escreva-os em markdown (`.md`).

Os prints de telas e protótipos ficam em `context/prototype/`.

## O que há aqui

- `design.md`: regras de uso do sistema de design.
- `prototype/grid.png`: grade de pontos cinza, o tabuleiro vazio.
- `prototype/grid-highlight.png`: a mesma grade com um ponto azul em destaque. Os pontos em volta dele ficam um pouco maiores.
